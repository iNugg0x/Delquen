# Changelog

All notable changes to this project are documented here.

## [2.0.0] - 2026-11-06

First public version, released under the name **Delquen** (earlier internal builds were called GPAI).

### Added
- Native C++/Win32 overlay: large colour-coded FPS, average / 1 % low / 0.1 % low, frame time, frame-time graph with stutter markers, CPU / GPU / RAM / VRAM
- Transparent per-pixel-alpha overlay with drag-to-move (grid and edge snapping), click-through lock, compact and full layouts
- Main window with Overlay, Sensors, Settings and Games tabs; light / dark / system theme
- Automatic game detection; overlay shown only while a game runs; include / ignore lists
- Per-game profiles (position, size and sensors)
- Session recording: per-second CSV per session and a `history.csv` summary
- DirectX FPS via DXGI; OpenGL / Vulkan via DxgKrnl events (experimental)
- GPU usage and VRAM on AMD / Intel through Windows counters and DXGI; NVIDIA via NVML
- 22 languages (switch at install time and in Settings; Arabic with mirrored layout)
- Tray icon, background mode, start with Windows (scheduled task)
- Inno Setup installer with language selection
- Automatic migration of the old `%APPDATA%\GPAI` data folder
- New logo and application icon (embedded in the executable), installer artwork, README banner and social preview, all regenerated by `tools/make_logo.py`

### Known issues
- Exclusive fullscreen hides the overlay (use borderless / windowed)
- OpenGL / Vulkan detection may miss some games
- CPU temperature unavailable; GPU temperature NVIDIA-only
